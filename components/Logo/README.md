Affiche un logo officiel fourni, jamais redessiné ni recoloré.

**Ce que vous fournissez :** `section` (`"cdvp"` comité, `"handi"` section Handi-Planeur) ; `version` ; `taille` en px (carré, défaut 160) ; `alt` si besoin (`""` quand le nom est écrit juste à côté).

| version | CDVP41 | Handi-Planeur | quand |
| --- | --- | --- | --- |
| `fond-blanc` | défaut | ✓ | fond blanc, bureautique |
| `transparent` | — | défaut | salamandre blanche, fond transparent : sur `paper` (couverture du programme) et fonds clairs |
| `contour` | ✓ | ✓ | salamandre ajourée : textile, marquage, fond clair uni |

Tailles du programme : 340px en couverture, 78px en en-tête de page intérieure (à droite du titre). Le lettrage est `navy-700` : jamais sur `surface-dark`.
