Bandeau marine avec le logo d'un partenaire dans un cartouche blanc.

**Ce que vous fournissez :** `titre` ; `surtitre` facultatif (« Financement acquis ») ; `children` facultatif ; `logo` et `logoAlt` (défaut : Agence nationale du Sport) ; `pleinePage` pour le bas de couverture (« Avec le soutien de »).

Le logo partenaire reste toujours dans son cartouche `white` : jamais posé directement sur le marine. N'utiliser le logo ANS que pour les actions qu'elle finance.
