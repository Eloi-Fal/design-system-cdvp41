Point numéroté : pastille ronde, intitulé et texte.

**Ce que vous fournissez :** `numero` ; `titre` (une phrase courte, sans point) ; `children` (1 à 2 phrases) ; `ton` (`"rouge"` défaut, `"marine"`) ; `encart` pour poser l'étape sur un fond `mist` arrondi.

- Liste d'arguments (« Pourquoi ») : pastilles 28px `red-600`, sans encart, écart 14px.
- Options au choix (« Deux façons d'en profiter ») : `encart`, pastilles 30px ; la première `marine`, la seconde `rouge`.
Trois étapes au plus par liste.
